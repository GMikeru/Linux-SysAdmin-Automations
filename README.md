# Linux SysAdmin Automations

Welcome to the **Linux SysAdmin Automations** repository. 
This portfolio contains a collection of advanced Bash scripts designed to automate system administration, manage security permissions, and streamline developer environments on Linux endpoints.

## 🚀 Deployment Methods
These scripts are designed to be platform-agnostic and have been successfully deployed in production using:
* **Canonical Landscape** (Ubuntu/Linux environments)
* **Microsoft Intune** (Custom scripts for supported endpoints)
* **Manual Execution** (Standard Bash execution)

## 📁 Repository Structure
| Package | Description |
|---|---|
| [Configure-LeastPrivilegeEnvironment](./Configure-LeastPrivilegeEnvironment) | Uses Polkit and sudoers drop-in files to allow developers to manage OpenVPN, Charles Proxy, and /etc/hosts without requiring full root access. |
| [Install-MongoDBToolchain](./Install-MongoDBToolchain) | Idempotent script to install MongoDB Server, Shell, and Compass, including granular sudoers aliases for developer service management. |
